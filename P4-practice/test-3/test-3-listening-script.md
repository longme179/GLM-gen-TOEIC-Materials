# Full Practice Test 3 — Listening Script

**Bands:** B1 B2 B3 B4 B5 · **For:** the person or app reading the test aloud · **Do not show this file to the test taker before the session**

*VI: Kịch bản nghe của đề thi thử số 3. Người đọc (hoặc ứng dụng đọc văn bản) đọc đúng theo văn bản, giữ các khoảng ngắt như đã đánh dấu. Người làm bài không được xem file này trước.*

## Reader instructions

- Read at a natural, calm pace — not slow-motion. This replaces the test audio (see FORMAT.md).
- **Part 1:** read the scene card description only if the test taker cannot see the questions file. Then read the four statements (A)–(D) with about 4 seconds between them; test taker marks one.
- **Part 2:** read the question, then the three responses (A)–(B)–(C) with ~2-second gaps; 5 seconds after the last response.
- **Parts 3–4:** read the direction line, then the conversation/talk straight through. Obey every `[PAUSE …]` mark — the test taker uses that time to read ahead and answer.
- If using a TTS app: process one block at a time in order; never let the app read two blocks without the marked pause.

### Conversation 1 (Questions 1–3)
W: Morning, Mateo. Line three is running about twenty percent slower than yesterday. Can you take a look?
M: I already checked the control panel — no error codes. But the conveyor sounded strange on my walk-through: a squeaking noise near the motor.
W: The belt again? We had to replace the one on line two last month.
M: I think that's it. The belt looks worn near the drive pulley, so it's probably slipping. That would explain why the whole line has slowed down.
W: All right. We have a large order of solar chargers due to ship on Friday, so we can't fall behind.
M: I'd rather not stop the line while it's running. I can install a new belt during the lunch break — it takes about forty minutes.
W: Good. I'll have the team take their lunch at eleven thirty instead of noon.
M: Perfect. I'll go to the parts storeroom now and grab a spare belt so everything is ready.
