# Full Practice Test 2 — Listening Script

**Bands:** B1 B2 B3 B4 B5 · **For:** the person or app reading the test aloud · **Do not show this file to the test taker before the session**

*VI: Kịch bản nghe của đề thi thử số 2. Người đọc (hoặc ứng dụng đọc văn bản) đọc đúng theo văn bản, giữ các khoảng ngắt như đã đánh dấu. Người làm bài không được xem file này trước.*

## Reader instructions

- Read at a natural, calm pace — not slow-motion. This replaces the test audio (see FORMAT.md).
- **Part 1:** read the scene card description only if the test taker cannot see the questions file. Then read the four statements (A)–(D) with about 4 seconds between them; test taker marks one.
- **Part 2:** read the question, then the three responses (A)–(B)–(C) with ~2-second gaps; 5 seconds after the last response.
- **Parts 3–4:** read the direction line, then the conversation/talk straight through. Obey every `[PAUSE …]` mark — the test taker uses that time to read ahead and answer.
- If using a TTS app: process one block at a time in order; never let the app read two blocks without the marked pause.
