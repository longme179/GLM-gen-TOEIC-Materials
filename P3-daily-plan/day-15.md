# Day 15 — Part 6: Text Completion & Cohesion
**Bands:** B1 B2 B3 B4 B5 · **Time:** 60 minutes · **Focus:** Part 6 — the whole-text-first method plus the two cohesion patterns (transitions, parallel structure)

*VI: Hôm nay học Part 6: đọc trọn đoạn văn trước khi nhìn phương án, cộng hai pattern liên kết — từ nối và cấu trúc song song.*

Không ghi chú, không đáp án; câu làm lại vẫn sai quay về đầu sổ với phần mổ xẻ sắc hơn.*

## Focused skill (15 min)
Read P2-reference/part-6-strategy.md, section "The Method — Context First, Blanks Second": the 30–45-second whole-text read and the three silent questions (What is this text for? Who is reading it? What does each paragraph do?). Then open P2-reference/grammar-atlas-2-clauses-connectors-word-forms.md and study Pattern 9 — Sentence Transitions for Cohesion (however / therefore / moreover / that said) and Pattern 10 — Parallel Structure in Lists and Comparisons: read each rule and redo each pattern's example item cold. These two patterns decide the blanks that grammar alone cannot.

*VI: Đọc P2-reference/part-6-strategy.md, mục "The Method — Context First, Blanks Second": lượt đọc trọn đoạn 30–45 giây và ba câu hỏi thầm (Đoạn văn này để làm gì? Ai đang đọc nó? Mỗi đoạn nhỏ đảm nhiệm việc gì?). Sau đó mở P2-reference/grammar-atlas-2-clauses-connectors-word-forms.md và học Pattern 9 — từ nối tạo liên kết (however / therefore / moreover / that said) và Pattern 10 — cấu trúc song song trong liệt kê và so sánh: đọc quy tắc của từng pattern và làm lại nguội câu ví dụ của từng pattern. Hai pattern này quyết định những chỗ trống mà riêng ngữ pháp không giải quyết được.*

## Drill (25 min)
P4-practice/drills/part-6-drills.md — Set A — Foundation (1 text, 4 blanks); B3–B5 add Set B — Core (1 more text, 4 blanks). Protocol per text: read the whole text once with the options COVERED (~40 seconds); write one line under it stating its purpose and reader (for example: "memo from operations to warehouse staff — closing forces early collection"); only then uncover the options and take the blanks in order, classifying each one first (word form / tense-voice / preposition / word choice / cohesion); budget about 2.5 minutes per text; finish with the one-breath final sweep. Then the key, reading every Why and Traps line.

*VI: File P4-practice/drills/part-6-drills.md — Set A — Foundation (1 đoạn, 4 chỗ trống); B3–B5 thêm Set B — Core (thêm 1 đoạn, 4 chỗ trống). Quy trình mỗi đoạn: đọc trọn đoạn một lần trong khi CHE các phương án (~40 giây); viết một dòng bên dưới nêu mục đích và người đọc của đoạn (ví dụ: "bản ghi nhớ từ bộ phận vận hành gửi nhân viên kho — việc đóng cửa buộc phải lấy hàng sớm"); chỉ sau đó mới mở phương án và làm từng chỗ trống theo thứ tự, phân loại mỗi chỗ trước (dạng từ / thì-thể / giới từ / chọn từ / liên kết); ngân sách khoảng 2,5 phút mỗi đoạn; kết thúc bằng lượt quét trong một hơi đọc. Sau đó mới xem đáp án và đọc hết các dòng Why và Traps.*

## Band adjustments
- **B1:** Set A only; anchor the first read on the To/From/Subject lines; attempt the blanks you can classify instantly plus the cohesion blank (prefer the option that keeps the text moving in the same direction); every blank you skip is still logged as a row.
- **B2:** Set A; work all four blanks in order; drill the big-four connectors (so, however, in addition, for example) until their logic is reflexive; on any insertion blank, check every pronoun in the option for a partner noun nearby.
- **B3:** Set A + Set B; predict each blank's type BEFORE reading its options; re-read only the affected sentence, never the whole text.
- **B4:** Set A + Set B at about 2 minutes per text; hold the text's structure from the single read; test insertion options by reading them together with the sentence that follows.
- **B5:** Set A + Set B, both inside 5 minutes total; spend the saved attention on subtle cohesion — moreover versus for instance, this versus that, register consistency.
